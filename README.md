# Рекомендательный сервис для ритейла

Гибридная система рекомендаций, сочетающая CatBoostRanker и item-based рекомендации (Annoy).

##  Логика работы

Система классифицирует пользователей на три типа и формирует рекомендации в зависимости от типа:

### 1. **Новый пользователь**
- 2 самых популярных товара среди активных пользователей
- 1 товар от item-based модели, похожий на самый популярный

### 2. **Пассивный пользователь** (1-3 действия на платформе)
- 2 товара, похожих на случайный товар из истории пользователя (контентная модель)
- 1 самый популярный товар среди активной группы

### 3. **Активный пользователь** (4+ действий на платформе)
- 3 товара от CatBoostRanker (исключая уже взаимодействовавшие)
- К каждому товару от ranker item-based модель находит 2 похожих товара
- Все товары умножаются на веса (вес контентных товаров = 0.7)
- Выбираются 3 товара с максимальным весом

##  Архитектура

### Модели:
- **CatBoostRanker** — ранжирование товаров для активных пользователей
- **Annoy (item-based)** — поиск похожих товаров
- **Контентная модель** — рекомендации по схожести товаров

### Преимущества подхода:
- Поддержка пользователей с разным уровнем активности
- Сбалансированное сочетание персонализированных и популярных рекомендаций
- Диверсификация рекомендаций (продвижение новых и менее популярных товаров)
